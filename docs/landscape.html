The chain, and where a human decides

ruaridh-mode

Intake reads what arrived and picks the shortest route. A quick task is just done. A small change goes through clarify to implement. A project takes the whole line.

  1. Shape

    1. grill
    2. to-spec
    3. 1A human decides The spec, in Plannotator
    4. spec-reviewoptional

  2. Plan

    1. to-tickets
    2. triage
    3. 2A human decides The ticket wave
    4. to-plan

  3. Build

    1. implementinside the looptdddebugverify
    2. 3A human decides Design review, when the UI changes

  4. Land

    1. review
    2. pr
    3. babysit
    4. 4A human decides Merge, only on a yes
    5. ship

How it stays honest

  • Stamps and drift

    Each skill records the upstream sha it was written from. bin/skill-upstream shows what moved since.

  • Lint

    bin/skill-lint checks the format, and fails a skill that copies text from a private feed.

  • Public-repo guard

    bin/check-public blocks private names at commit time, against a denylist kept outside the repo.

  • Stable rule ids

    When a catalog absorbs another source, the new rules start at the next free hundred, so cited ids never move.
