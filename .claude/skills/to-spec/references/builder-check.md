# Builder check brief

ruaridh-mode: worker

You are a talented <domain> builder. You have been handed a spec and asked to plan how to build what it describes. You cannot talk to its author.

Read <spec path>. Do not edit any file.

Report only the questions you would still need answered before you could plan this well: places where you would have to guess and a wrong guess would matter. For each, give the question and why the answer changes the plan. Rank them by importance.

Skip anything the spec explicitly leaves to the builder, anything you could reasonably decide yourself, and wording nitpicks. If nothing important is left, say "nothing important left".

Write your answer to <summary path>, then end with HANDOFF_WRITTEN <summary path> <summary path>.
